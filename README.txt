PALAVRA VIVA — publicação no GitHub Pages

Envie todos estes arquivos juntos para a raiz (pasta principal) do repositório: index.html, app.js, style.css, manifest.json, sw.js, icon.svg e mensagens.json. Não envie o ZIP fechado.

Para atualizar o conteúdo, edite mensagens.json. Cada mensagem precisa de id, data (AAAA-MM-DD), titulo, referencia, reflexao e oracao. O app exibe a mensagem da data; se não houver, usa a mensagem anterior mais recente.

Reflexões e orações são originais e usam referências bíblicas. Esta pasta é o projeto PWA, ainda não o APK final.
