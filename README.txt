PALAVRA VIVA — Bíblia completa + mensagem diária

A atualização acrescenta uma Bíblia de 66 livros (1.189 capítulos) com navegação por livro/capítulo, busca por palavras/frases, favoritos de versículos, mensagem diária, oração, favoritos da mensagem e compartilhamento.

Arquivos a publicar na raiz do repositório:
index.html, app.js, style.css, manifest.json, sw.js, icon.svg, icon-192.png, icon-512.png, mensagens.json e biblia.json.

Bíblia: texto de João Ferreira de Almeida classificado como Public Domain na coleção open-bibles. Fonte e dados originais: https://github.com/seven1m/open-bibles (arquivo por-almeida.usfx.xml). A coleção identifica essa versão portuguesa como domínio público. Crédito mantido no app.

Reflexões e orações são originais. A pasta biblia.json contém o texto completo para leitura e busca no aparelho após o primeiro carregamento; o service worker tenta guardá-lo para uso offline.

Para atualizar mensagens diárias, edite mensagens.json. Cada item possui id, data (AAAA-MM-DD), titulo, referencia, reflexao e oracao. A versão incluída traz sete mensagens iniciais, de 11 a 17 de outubro de 2026.

Depois de atualizar os arquivos, espere o GitHub Pages publicar a nova versão e limpe/atualize os dados em cache se o aparelho continuar mostrando a versão anterior. A versão instalada existente pode precisar ser atualizada pelo mesmo método de assinatura usado ao gerar o APK.
